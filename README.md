## Purpose
With this project you can send yourself 1 lamport on the dev-net and fetch the latest intializemint or create liquidity pool transactions on the solana blockchain and print their keypairs.

## Prerequisits 
1. Specify your keypair under /.config/solana/id.json using the solana CLI
2. Installed Rust

## How to get started
``` rust
cargo build
cargo run
```
